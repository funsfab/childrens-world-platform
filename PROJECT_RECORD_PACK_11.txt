PACK 11 PROJECT RECORD — CURRENT WORKING IMPLEMENTATION

- Three access states: Visitor / Trial / Active.
- Parent registers the family; child does not independently register by email.
- Trial is currently modeled as 7 days, limited, no card required.
- Child profile uses nickname, age band and avatar in prototype.
- Locked child-facing content avoids prices and aggressive sales language.
- Parent Centre owns membership and billing actions.
- Full World activation is test-mode only in this pack.
- Trial expiry, entitlements and profile progress will move to secure backend/database in production.
- Exact trial duration, pricing and plan structure remain provisional.
- Build Pack 11 v0.2 adds five protected responsive viewing modes: mobile portrait, mobile landscape, tablet portrait, tablet landscape and desktop.
- Responsive corrections should be made in the original protected mode block in css/style.css; do not stack later override chains.
